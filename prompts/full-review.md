# Full Paper Review Prompt

Use the paper-review workflow to review this ML/AI paper like a rigorous NeurIPS/ICML/ICLR reviewer.

Inspect the available PDF, LaTeX source, bibliography, checklist, figures, appendix, supplementary material, and code artifact. Produce:

1. artifact inventory
2. venue/contribution calibration
3. central claims and support matrix
4. strengths
5. P0/P1/P2 weaknesses with evidence anchors
6. section-by-section findings
7. math/algorithm audit if applicable
8. experiment/table/figure audit
9. likely reviewer attacks
10. score, confidence, and rationale
11. prioritized revision plan

Do not summarize only. Stress-test claims and make each serious issue falsifiable.
