# Artifact Release Audit Prompt

Audit this research artifact, source zip, or GitHub repository for paper submission, artifact evaluation, or public release.

Inspect README, environment files, scripts, configs, checkpoints, data instructions, logs, result files, license, citation, hidden files, and package contents. Check:

- runnable quickstart boundary
- paper-to-artifact alignment
- table/figure traceability
- config and hyperparameter consistency
- anonymity and secret leaks
- stale files, cache files, old titles, local paths
- license/data/model redistribution risks
- README wording accuracy

Output artifact verdict, inspected contents, runnable boundary, paper-alignment findings, anonymity/security/license findings, P0/P1/P2 fix list, and suggested README wording.
